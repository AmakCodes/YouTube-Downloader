📖 How to get cookies.txt

Method 1: Browser Extension (Easiest)

  1. Install extension for your browser:
    • Get cookies.txt LOCALLY (Chrome/Edge)
    • cookies.txt (Firefox)
  2. Go to YouTube.com and log in
  3. Click the extension icon → Export → Save cookies.txt
  4. Upload the file using the button above

Method 2: Command Line (Advanced)

yt-dlp --cookies-from-browser chrome --cookies cookies.txt https://youtube.com/watch?v=VIDEO_ID

Then upload the generated cookies.txt file.

⚠️ Cookies expire after a few days. Re-upload if downloads stop working.

Skips the server-side staging step — faster, but no downloads-history entry, no pause/resume, and no progress bar (your browser's own download UI takes over). Playlists come down as a single .zip, built on the fly — slower than the regular playlist download since videos are processed one at a time.
